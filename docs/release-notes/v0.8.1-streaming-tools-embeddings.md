## 兼容性 / Compatibility

- **行为级变更（诚实声明）**：bigrams 去重+latin 整词化会改变
  `MemoryStore::retrieve` 对既有语料的**排序结果**（词法更准，但与
  0.8.0 的逐位排序不可比）。依赖旧排序的宿主请锁定 0.8.0。
- **非破坏 API**：`complete_stream_with_tools` / `EmbeddingProvider` /
  `retrieve_embedded` 均为新增面（trait 方法带默认实现），0.8.0 代码
  无需改动即可编译。
- **新增 feature 门控**：`HttpEmbeddingProvider` 在 `native-http` 后
  （与 HttpProvider 同门）；`HashEmbeddingProvider` 默认可用。
- crates.io：`0.8.1` 全链发布（common→pal→core→ecs→asset→render→
  subsys→infer→genai→agent→pc）。
