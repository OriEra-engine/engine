## 中文版

OriEra 是一个 AI 原生、虚实融合、可自演化的开放数字世界引擎。
这是我们的第一个公开 release——不追求功能完整，重点是把**架构骨架、五端接入、开源治理**三件事立住，欢迎社区共建。

### 这个版本有什么

- **十一层架构骨架**：L1 PAL → L11 应用层，每个 crate 都已在 workspace 里就位。
- **五端一等公民接入**：PC / 移动 / Web / AR 眼镜 / 脑机接口（预留）。
  - 上层代码只读 `Capabilities` 位图，不写 `#[cfg(target_os)]`。
  - 脑机接口只留 bit 40+ 位和 proto 消息，v1 不接硬件。
- **L1 PAL 可运行 demo**：`examples/01-hello-triangle/`，浏览器直接打开，点选五个端看能力位图 + WebGPU 三角形。
- **跨语言契约**：`contracts/oriera/pal/v1/` 已定义 capability 与 spatial input 两个 proto。
- **架构门禁模板**：`manifests/L1-pal.yaml`，CI 未来据此自动检查依赖方向、预算、降级策略。
- **开源治理**：Apache-2.0、DCO、BDFL + Core Team、RFC 流程、路线图。

### 明确不包含

- 还没有可玩的 demo（三角形不算 demo）
- 还没有 ECS、渲染、物理、Agent 的实质实现
- Rust 侧尚未在 CI 跑通（本地需 Rust 1.80+）

## English

OriEra is an AI-native, mixed-reality, self-evolving open digital world engine.
This is our first public release. We are not shipping features yet — we are shipping **the architectural skeleton, the five-platform abstraction, and the open-source governance**. We invite the community to build with us.

### What's in this release

- **11-layer architecture skeleton**: every layer from L1 PAL to L11 App is wired into the Cargo workspace.
- **Five first-class platforms**: PC / Mobile / Web / AR glasses / BCI (reserved).
  - Upper layers only read a `Capabilities` bitfield; no `#[cfg(target_os)]` in application code.
  - BCI (bits 40+) is stub-only in v1 — no hardware, no frame budget impact.
- **Runnable L1 demo**: `examples/01-hello-triangle/` — open in any WebGPU browser, switch between the five platforms, watch the capability bitmap and a WebGPU triangle.
- **Cross-language contracts**: `contracts/oriera/pal/v1/` ships `capability.proto` and `spatial_input.proto`.
- **Architecture manifest template**: `manifests/L1-pal.yaml` — CI will soon enforce dependency direction, budgets, and degradation rules from this file.
- **Open governance**: Apache-2.0, DCO, BDFL + Core Team, RFC process, public roadmap.

### What's explicitly NOT in

- No playable demo (a triangle doesn't count).
- No real ECS, renderer, physics, or Agent runtime yet.
- Rust CI is not green yet (local dev needs Rust 1.80+).
