# v0.3.0 — L8 生成式 AI 骨架落地 / Native Generative AI Skeleton

发布日期 / Release date: 2026-10-16

---

## 中文版

v0.2 给引擎「加了润滑」，v0.3 把原计划 2028 年的 **L8 生成式 AI 骨架提前落地**
（ADR 0003）：文生 3D 资产的引擎边界、校验与入库通路全部打通，深度管线留给 2028。

### 核心变更

- **`crates/oriera-genai`（L8）**：`GenerationProvider` trait 边界 + `MockProvider` +
  `validate_asset` 校验。Tripo / Seedance 协议适配器随 `providers` feature 门控——
  只定义 JSON shape，**零 HTTP client**，transport 由壳层注入（wasm 体积可控）。
  生成不走 L7 推理：两条独立边界（ADR 0003）。
- **引擎环集成**：`GenAiSystem` 限量轮询生成任务 → 校验 → `PendingSwaps` +
  `AssetLanded` 事件；壳层 `hot_swap::apply_pending` 把生成物落入 L4 命名资产
  （v0.2 铺的热替换轨道首次实战）。L9 已有生成意图入口。
  示例：`cargo run -p oriera-genai --example hotswap`。
- **契约与治理**：`contracts/oriera/genai/v1`（Protobuf）、`manifests/L08-genai.yaml`、
  ADR 0002（神经渲染运行时不变量）与 ADR 0003（L8 原生生成式 AI）入库。
- **crates.io 就绪**：workspace 版本 0.3.0，全部 crate `version/repository` 继承
  workspace 元数据，发布配置齐备。
- **文档**：架构文档依赖图、逐层详解、目录地图同步 L8 现状（与 #42/#44 的
  完整版文档结构融合）。

### 兼容性

加法式变更：现有 API 语义不变；`providers` 默认关闭，默认构建零新增依赖。

### 验证

CI（Linux）fmt / build / test / clippy 全绿；维护者 review 留档于 PR #41。

## English

v0.2 lubricated the engine; v0.3 lands the **L8 generative-AI skeleton ahead
of schedule** (ADR 0003, deep pipeline still 2028): the engine boundary for
text-to-3D asset generation, validation and ingestion is fully wired.

- **`crates/oriera-genai` (L8)**: `GenerationProvider` trait boundary +
  `MockProvider` + `validate_asset`. Tripo / Seedance protocol adapters behind
  the `providers` feature — JSON shapes only, **zero HTTP clients**;
  transport stays injected by the shell (wasm-budget friendly). Generation
  does not go through L7 inference: two independent boundaries (ADR 0003).
- **Engine-loop integration**: `GenAiSystem` rate-limits generation polls →
  validates → emits `PendingSwaps` + `AssetLanded`; the shell's
  `hot_swap::apply_pending` lands results into L4 named assets (the v0.2
  hot-swap rail sees its first real use). L9 gains generation intents.
- **Contracts & governance**: `contracts/oriera/genai/v1` (Protobuf),
  `manifests/L08-genai.yaml`, ADR 0002 (neural-rendering runtime invariants)
  and ADR 0003 land in-tree.
- **crates.io-ready**: workspace version 0.3.0 with inherited package
  metadata across all crates.
- Additive-only: existing API semantics unchanged; `providers` is
  off by default (zero new deps in default builds).
