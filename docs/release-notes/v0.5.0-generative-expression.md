# v0.5.0 — 生成式表达内生 / Generative Expression

发布日期 / Release date: 2026-10-17

---

## 中文版

小 3D AI 原生游戏「渲染很差」的根因不是渲染器，而是生成能力没有
长在引擎里——L8 此前只有文生 3D/视频骨架，浏览器内核侧甚至是零。
这一版把**模型能力补成引擎器官**：一句话主题，引擎生成天空、地面、
海报（可选 3D 道具），校验后热替换落位，离线也有体面的程序化表达。

### 七个落点

- **L8 `text_to_image` 种类（RFC 0001）**：小 3D 游戏表达的主力——
  天空穹顶、地面 albedo、海报、精灵图全是 still 图。契约加法式变更
  （proto3 枚举/字段，旧读取方安全忽略），停留在 v1。
- **CogView 适配器**：说 OpenAI **images 方言**
  （`POST {base}/images/generations`），智谱开放平台为默认 base，
  OpenAI images / 任意兼容网关只是 `base_url`/`model` 数据差异。
  同步端点映射到任务语义：submit 零网络，阻塞调用落在首个 poll 切片，
  `b64_json` 一次完成、签名 URL 二次完成（下载不带 Authorization）。
  自带手写 base64 解码器——`providers` feature 依旧零新增依赖。
- **按格式匹配的占位降级**：图片槽失败落一张**真实可解码的 1×1 PNG**
  （运行时构造，块级 CRC/Adler-32 经真实解码器验证），网格槽落空场景
  GLB——渲染端的解码器永远不会收到读不了的字节（ADR 0003 判据 3 细化）。
- **浏览器内核镜像 `engine/genai.js`**：边界词汇（kind/capabilities/
  校验/计量/占位降级）与 Rust 一一对照；fetch 的 Promise settling 取代
  request/poll 轮询节拍。浏览器侧从此有 L8。
- **`ArtDirectorSystem` 美术导演**：提示词形状（天空该长什么样）是引擎
  知识；应用只说主题，不碰 prompt 拼装。
- **L4 热替换 + L5 槽位消费（JS 镜像）**：`AssetStore.insertNamed`
  同名原位换芯；`SlotBindings` 把命名资产绑到材质贴图 / GLB 网格，
  落地自动换、不重建场景。
- **demo 13 生成式画廊**：打开即见纯色世界，半秒后 L8 自动装帧；
  「表达对比」开关直接展示纯色 ⇄ 生成的差别；离线程序化兜底
  （确定性贴图），⚙ 里填 CogView/Tripo Key 即真实生成
  （自动复用 demo 11 存过的智谱 Key）。

### 质量口径

- Rust：`oriera-genai` 50 项测试（providers feature 口径），
  新增 CogView 双路径（URL/b64）、base64 向量、按格式占位、
  契约门禁全绿。
- 契约：`genai.proto` 加法 + `docs/rfcs/0001-genai-text-to-image.md`；
  L08 manifest 同步（34 契约不变）。
- 兼容性：全部为加法式变更，现有 demo 的 API 语义不变。

## English

The reason small 3D AI-native games "render poorly" was never the
renderer — it was that generation capability didn't live inside the
engine. L8 had only text-to-3D/video skeletons, and the browser kernel
had nothing at all. This release turns **model capability into an
engine organ**: one theme sentence in, generated sky / ground / posters
(and optional 3D props) out — validated, hot-swapped, and decent even
offline.

- **`text_to_image` kind (RFC 0001)** — the highest-leverage kind for
  small 3D games: skydomes, ground albedo, posters, sprite sheets.
  Additive contract change, stays on v1.
- **CogView adapter** — speaks the OpenAI images dialect; Zhipu by
  default, OpenAI/any gateway via config. Synchronous endpoint mapped
  onto task semantics (submit does no I/O; the blocking call lands in
  the first poll slice). Hand-rolled base64 keeps the `providers`
  feature dependency-free.
- **Kind-matched placeholder degrade** — a failed still lands a real,
  decoder-verified 1×1 PNG; a failed mesh lands an empty-scene GLB.
  Renderers never receive bytes they cannot parse.
- **Browser kernel mirror `engine/genai.js`** — the L8 boundary
  vocabulary maps 1:1 to Rust; fetch promise settling replaces the
  poll cadence.
- **`ArtDirectorSystem`** — prompt shapes are engine knowledge;
  applications state a theme, never assemble prompts.
- **L4 hot swap + L5 slot bindings (JS mirror)** — named assets swap
  in place; slots bind names to material textures / GLB meshes.
- **Demo 13 Generative Gallery** — watch a flat-color world get
  art-directed in seconds; expression-compare toggle shows before/after;
  offline procedural fallback; bring a CogView/Tripo key for real
  generation (reuses the café demo's saved Zhipu key).

Quality: 50 `oriera-genai` tests (providers feature) green; contract
gate green; all changes additive — existing demo APIs unchanged.
