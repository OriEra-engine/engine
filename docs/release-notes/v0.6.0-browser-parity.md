# v0.6.0-browser-parity — Browser Kernel v2: Command Channel × Injectable Cognition × Open-Model Supply

**日期 / Date**: 2026-10-19 · 分支基线 / Baseline: main @ 7993dcd

## 为什么升级 / Why

八赛道可行性实战（out/verticals 七案 + 言出法随）交叉验证出的内核缺口，
全部是「同一件事 Rust 侧有、浏览器侧没有」或「写死导致垂直版翻不动」：

Gaps cross-verified by the seven-vertical feasibility run: things the Rust
side has but the browser kernel lacks, plus hardcodes that block verticals.

## 兼容性 / Compatibility

全部加法式：不传新参数时线协议与行为逐位不变（测试钉死：默认场景仍为
隅角咖啡馆、max_tokens 默认 260、容量默认 60、rule/无 key 仍返回 null 走降级）。

Additive only — defaults are bit-compatible with v1 (pinned by tests).
