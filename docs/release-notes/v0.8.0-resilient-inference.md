# v0.8.0-resilient-inference — Circuit Breaker × Determinism Grades × Fingerprint Ledger × Bounded Prompts

**日期 / Date**: 2026-10-21 · 计划 / Plan: PLAN-deepseek-upgrade 第二批（新 landscape 修订版，创始人指令续批）

## 为什么升级 / Why

第一批回答"模型多贵"，第二批回答"**模型多靠得住**"——云端挂了世界
怎么办？模型的随机性在回放里算什么？玩家粘十 MB 文本进来谁兜底？
四问四答，全走引擎内脏，不靠祈祷。

Batch two answers "how dependable is the model": circuit breaker for
outages, graded replay promises for randomness, bounded prompts for
hostile input — all inside the engine.

## 兼容性 / Compatibility

全部加法式：`ModelProvider` 新增带默认实现的 `determinism()`；现有
provider 行为不变；`FallbackProvider` 是新类型，默认工厂不换——壳层
自愿升级；`fit_budget` 默认 2000 字符只裁超出预算的极端世界。

Additive only: default-method trait growth, new opt-in types, and a
budget that only bites worlds whose prompts actually balloon.

## 已知边界 / Known Boundaries

- 熔断失败率与 L2 `BudgetAllocator` EWMA 的自动联动留作 follow-up
  （信号已由 `health_report()` 暴露，接线待 L2 拨杆评审）；
- `InferenceLedger` 的 prompt 指纹按世界侧视角计算（provider 标签入
  哈希），provider 侧精确指纹（model+seed）随 B1 InferRequest 合流。
