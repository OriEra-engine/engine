# v0.2.0 — 全层润滑剂 / All-Layer Lubricant Pass

发布日期 / Release date: 2026-10-15

---

## 中文版

AI 原生应用的负载是**概率性、突发、昂贵**的：模型调用会突然吃掉 200ms，
生成管线会倾泻一批资产，幻觉会写出 `1e9` 的倍速。这一版不给引擎加新系统，
而是给已有的十一层**每层加一次润滑**——把 AI 的毛刺在引擎内吸收掉，
让上层以为世界永远是平滑的。

### 每层一个摩擦点，每层一刀

- **L0** `TokenUsage`：全引擎统一的 token 计量词汇（L7 产出 / L9 累计）。
- **L1** `route(caps, RouteHint)`：端云路由在 PAL 一次决策；隐私任务
  （语音/摄像头）无条件钉在端侧，NPU 吃小负载，紧延迟走边缘。
- **L2** `Scheduler::system_timings()`：逐系统毫秒——「这帧被谁吃了」一眼可见；
  `with_budget_ns` 按平台画像 grading（AR 眼镜 90fps 不再被 60fps 曲线误判）。
- **L3** `for_each_mut` 零分配（去掉每帧 O(n) 克隆）；`resource_or_default`
  自愈资源；`write_event`/`take_events` 类型化事件队列。
- **L4** `insert_named`/`get_named`：命名资产**原位热替换**——AI 重新生成的
  贴图/网格同名换入，实体零重建；`unload` 释放。这是 L8 生成管线的落地点。
- **L5** `observe_frame` 迟滞画质调速：持续过载 → 降档 batching（1/4/16），
  真有余力才缓慢升档，中间带重置防抖。
- **L6** `TimeScale`：慢动作/子弹时间/暂停是一个资源；物理步长按它缩放，
  钳制 [0,8]，幻觉值最多变快进、不会 NaN 世界。
- **L7** 帧预算命令队列：单帧最多执行 N 条命令（默认 32），洪峰计入
  `deferred` 摊到后续帧；`ModelProvider::last_usage()` + `UsageMeter`
  让每次调用的 token 成本进世界状态。
- **L9** 认知/导演系统 `resource_or_default` 自愈启动（裸世界 boot 成为
  测试契约，不再帧中 panic）；`parse` 否定语义（「别清空」不再清空）。
- **L11** PC 壳全量接线示范：平台预算、画质调速、逐系统耗时报告、
  资产热替换、TimeScale 演示。

### 兼容性

全部为**加法式**变更：现有 API 签名不变，demo 10/11 的 kernel.js 镜像
无需改动；`Scheduler::new` 行为不变（默认预算仍 60fps 曲线）。

### 验证

`cargo test --workspace`（CI/Linux）；新增 28 个测试覆盖每层新契约（全仓 78 个）。

## English

The loads of AI-native apps are *probabilistic, bursty and expensive*.
This pass adds no new subsystem — it lubricates each of the eleven
existing layers so the engine absorbs the AI spikes before apps ever
feel them: unified token metering (L0/L7/L9), one-shot edge/cloud
routing at the PAL boundary (L1), per-system frame timings and
per-platform budget curves (L2), zero-alloc iteration + self-healing
resources + typed events (L3), named in-place asset hot swap (L4),
hysteresis quality governor (L5), clamped TimeScale pacing (L6),
frame-budgeted inference queue with deferred accounting (L7),
negation-aware parsing and panic-free cognition boot (L9), all wired
end-to-end in the PC shell (L11). Additive-only: no existing API
signature changed.
