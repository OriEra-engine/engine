# v0.5.1 — 咖啡馆点亮生成链 / The Café Joins the Pipeline

发布日期 / Release date: 2026-10-17

---

## 中文版

v0.5.0 让 demo 13 证明了「一句话装帧世界」；这一小步把**同一条
L8 生成链接进 demo 11 隅角咖啡馆**——世界活着，墙面就跟着剧情活。

- **`StoryboardArtSystem` 分镜画系统**（引擎侧，`genai.js`）：观察
  L9 导演的世界词汇 `world.story.beats`，每两拍为 `wall.art` 槽位
  提交一张「此刻的故事」插画。提示词形状（插画该长什么样）是引擎
  知识；世界只提供事实。
- **`imageProviderFromChatConfig`**：L7 聊天选型 → L8 图像端点的
  引擎内映射——用户在 ⚙ 存的智谱/OpenAI Key 无感复用为 CogView/
  images 生成；其余厂商与无 Key 情况降级为确定性程序化装帧。
- **应用层仍零模型代码**：demo 11 只多了一面墙（两窗之间的挂画
  槽位 + 射灯）和三行装配；降级语义为「保持原画不挂黑图」。
- 落位链与 demo 13 同源：`GenAiSystem` 校验 → `PendingSwaps` →
  `applyPending` → `AssetStore.insertNamed` → `SlotBindings` 原位换芯。

## English

v0.5.0 proved "one sentence re-frames the world" in demo 13; this
small step wires **the same L8 pipeline into demo 11, the Corner Café** —
while the world lives, its walls live with the story.

- **`StoryboardArtSystem`** (engine-side, `genai.js`): watches the
  director's world vocabulary `world.story.beats` and, every second
  beat, submits a "story-so-far" illustration to the `wall.art` slot.
  Prompt shape is engine knowledge; the world only supplies facts.
- **`imageProviderFromChatConfig`**: engine-side mapping from the L7
  chat selection to an L8 images endpoint — a saved Zhipu/OpenAI key
  lights up real generation with zero extra setup; anything else
  degrades to deterministic procedural framing.
- **The application stays model-free**: demo 11 gained one wall slot
  (framed plane + spotlight between the windows) and three lines of
  assembly; failure keeps the previous painting instead of a black quad.
