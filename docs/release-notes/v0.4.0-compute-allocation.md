# v0.4.0 — 算力分拨 / Compute Allocation

发布日期 / Release date: 2026-10-16

---

## 中文版

v0.2 的润滑剂让每层各自吸收毛刺；这一版把算力管控升级为
**一个账本 + 中央仲裁 + 各层拨杆**——帧预算**先分后花**，
浪费在进帧之前就消掉。管线的完整地图见
[docs/COMPUTE-BUDGET.md](../COMPUTE-BUDGET.md)。

### 五个微模型

- **L2 `BudgetAllocator` 分拨仲裁器**：每系统耗时做 EWMA，帧预算按平滑成本
  切成份额（每系统保底 5%）。唯一仲裁信号是 `Σ成本/预算`：持续超订 →
  全体按 `份额/成本` 比例节流（小系统保满速，下限 0.1 防饿死）；持续有余 →
  每次 +0.05 缓慢恢复；**预算之内不折腾**。节奏与 L5 调速器镜像
  （快降 30 帧 / 慢升 120 帧）。
- **L0 `ComputeGrant`/`Grants` 分拨词汇**：`{share_ms, throttle}` 一个结构体
  全引擎通用，经 `FrameCtx::grants` 借用下发（稳态零分配）。
  **查无此名 = 未纳管 = 满速**——植入新系统/新模型不需要先改仲裁器。
- **L7 自适应命令队列**：每帧执行预算 ×throttle（下限 1 条，队列只会
  变慢不会饿死）；`submit` 时对队尾做**可证安全**的合并——`Spawn` 求和
  （LCG 随机流逐位一致，有测试证明）、`SetGravity`/`Count` 取末值；
  `Teleport`/`SetSpeed` 因浮点无结合律**永不合并**。新增 `coalesced` 计数。
- **L6 物理空转跳过**：冻结时间或完全静止（零重力 + 全零速度）的积分
  是恒等无操作，整趟跳过（位级等价，`idle_frames` 可观测）。
  「看起来闲」的世界照常积分——近似永远是仲裁器的业务，物理层不做近似。
- **L9 注意力节拍器**：预算压力下认知/导演的说话间隔按 `1/throttle`
  拉长（封顶 8×），说话内容一字不动；玩家一碰世界
  （`world.write_event(WakeEvent)`）当帧回到基础节拍——
  **注意力是唯一高于账本的信号**。
- **L8 拨杆感知**：生成管线的 in-flight 上限与轮询间隔随压力缩放
  （封顶 8×）——生成是引擎里最可推迟的工作：压力下资产**晚点到，
  不会变差**。

### 管线梳理

- 每帧顺序固化为：**先分拨（allocate）→ 再运行（run with grants）→
  后观测（observe 回灌）**，闭环且无自证循环。
- PC 壳新增「L2 compute allocation」报告区（load / headroom / 每系统
  份额与节流百分比），与逐系统耗时表并列。
- 新文档 `docs/COMPUTE-BUDGET.md`：全景图、五个微模型的设计边界、
  植入新模型三步清单、确定性说明（调控≠语义，可 `AllocatorConfig::off()` 关断）。

### 兼容性

全部为加法式变更：`AllocatorConfig::off()` 下行为与 v0.3 逐位一致；
未读拨杆的系统照常满速运行；现有 demo 的 API 语义不变。

### 验证

`cargo test --workspace`（CI/Linux）；新增 28 个测试：仲裁器份额/节流/
恢复/关断、L7 拨杆缩放与合并等价性（世界逐位一致）、L6 空转位级等价、
L9 节拍/唤醒、L8 缓而不降级。

## English

v0.2 lubricated each layer's brakes; this release upgrades compute
governance to **one ledger, one arbiter, per-layer dials** — the frame
budget is allocated *before* it is spent, and waste is removed before
it enters the frame. Full map in
[docs/COMPUTE-BUDGET.md](../COMPUTE-BUDGET.md).

### Five micro-models

- **L2 `BudgetAllocator`**: per-system EWMA cost, budget split into
  floored proportional shares (5% minimum each). One honest signal —
  `Σcost/budget`: sustained over-subscription throttles every spender
  toward `share/cost` (cheap systems keep full speed, floor 0.1);
  sustained headroom recovers slowly; **in-budget frames are left
  alone**. Rhythm mirrors the L5 governor (degrade 30 / recover 120).
- **L0 `ComputeGrant`/`Grants`**: the shared `{share_ms, throttle}`
  vocabulary, handed down through `FrameCtx::grants` as a borrow
  (zero steady-state allocation). **Absent entry = unmanaged = full
  speed** — plugging in a new system or model never touches the
  arbiter first.
- **L7 adaptive command queue**: per-frame budget ×throttle (minimum
  one command — slowed, never starved) plus provably-safe submit-time
  coalescing: `Spawn` sums (bit-identical LCG stream, test-proven),
  `SetGravity`/`Count` keep the last; `Teleport`/`SetSpeed` never
  merge (floats are not associative). New `coalesced` counter.
- **L6 physics idle skip**: frozen time or a perfectly still world
  (zero gravity + exactly-zero velocities) makes integration a no-op —
  skipped wholesale, bit-identically, with an `idle_frames` readout.
  Nearly-still worlds still integrate: approximation belongs to the
  arbiter, never to physics.
- **L9 attention metronome**: under pressure the cognition/director
  speak interval stretches by `1/throttle` (cap 8×) with utterance
  content untouched; one `WakeEvent` (a player touch) restores base
  cadence on the same tick — attention outranks the ledger.
- **L8 grant-aware limits**: the generation in-flight ceiling and poll
  interval scale with pressure (cap 8×) — generation is the most
  deferrable work in the engine: under pressure assets land later,
  never worse.

### Pipeline

The tick order is now fixed: **allocate → run with grants → observe**.
The PC shell reports a "L2 compute allocation" table (load / headroom /
per-system share & throttle) next to the per-system timings.

### Compatibility

Additive only: with `AllocatorConfig::off()` behavior is bit-identical
to v0.3; systems that ignore the dial run at full speed; demo APIs
unchanged.

### Verification

`cargo test --workspace` (CI/Linux); 28 new tests covering allocator
shares/throttle/recovery/off, L7 scaling + coalescing equivalence
(bit-identical worlds), L6 idle-skip bit-equality, L9 cadence/wake,
L8 defer-not-degrade.
