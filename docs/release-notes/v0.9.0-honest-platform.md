## 为什么是 minor / Why 0.9.0

BREAKING：`PlatformProfile::web()` 与同步 `boot()` 返回保守基线；手机/AR
不再假定 NPU/显存等级/手势/眼动。0.x 语义下升 minor。

BREAKING: `web()` / sync `boot()` now return a conservative baseline;
phones/AR no longer assume NPU, VRAM tiers, gestures or eye tracking.
Semver: minor bump under 0.x.
