# v0.13.0 — crates.io 全链复航（勘误版）

> 日期：2026-11-14 ｜ 性质：crates.io 自 0.10.0 之后的首次全链发布（13 crate）＋ 发版流程勘误

## 勘误

v0.11.0 与 v0.12.0 的发版说明曾宣称「crates.io 全链发布」与「pip install oriera-sim==0.11.0/0.12.0」，经 2026-11-14 逐项实测：crates.io 上不存在任何 0.11/0.12 版本（10 个库 crate 自 0.10.0 后未再发布），PyPI 亦无 oriera-sim。根因：发版流程自 v0.11.0 起改走 tag → GitHub Release 流水线，遗漏了 crates.io/PyPI 步骤。

**补齐方式**：crates.io 以 **0.13.0** 跳版一次性全链发布（13 crate，见下清单）；PyPI oriera-sim 待 manylinux 构建就绪后首发。v0.11.0/v0.12.0 两篇说明已追加勘误记（原文保留不改写）。
